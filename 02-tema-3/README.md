## Sistemas de numeración

![Diapositiva 22](img/slide-22.png)

- Convierta 29110 en un número binario.
- 291/2 = 145 resto 1 (LSB)
- 145/2 = 72 resto 1
- 72/2 = 36 resto 0
- 36/2 = 18 resto 0
- 18/2 = 9 resto 0
- 9/2 = 4 resto 1
- 4/2 = 2 resto 0
- 2/2 = 1 resto 0
- 1/2 = 0 residuo 1 (MSB) Por tanto, 29110 = 1001000112
