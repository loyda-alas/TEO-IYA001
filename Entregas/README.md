## Cómo entregar

1. Entra en GitHub con tu cuenta (si no tienes, créala gratis en [github.com](https://github.com/signup)).
2. Haz un **fork** de este repositorio (botón **Fork**, arriba a la derecha). Desmarca la opción *Copy the `main` branch only* para que se copien también las ramas de entrega.
3. En **tu fork**, cambia a la rama de la entrega y, dentro de la carpeta `entregas`, crea tu carpeta con el formato `apellidoNombre` (por ejemplo, `entregas/perezAna/`). Sube ahí los archivos que pida el enunciado.
4. Abre un **pull request** desde la rama de tu fork hacia la **misma rama** de este repositorio (no hacia `main`). En el título pon tu nombre.
   - En *base* elige la rama de la entrega (por ejemplo, `programa-ensamblador`): GitHub propone `main` por defecto.

Los *pull request* no se aceptan: se quedan abiertos y la corrección se hace con comentarios en cada uno. La fecha del *pull request* es la fecha de tu entrega; los que se abran después del plazo se marcan automáticamente como **fuera de plazo**.
