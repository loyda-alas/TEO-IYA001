## Tipos de Señales

## Señales Continuas

Analógicas

Infinitos Valores

Sonido, luz, tiempo, temperatura

Radio

Bajo consumo de Ancho de Banda

+ Sensible al ruido y fallo

## Señales Discretas

Digitales

Binario (0, 1)

2 Valores/niveles 1 = On, Si, V

0 = Off, No, F

Finitos Valores

DVD

+ Capacidad de transmisión

+ Fácil compartir información

Son inmunes al Ruido
